# 🤖 AI News Agent — бесплатный автономный агрегатор новостей по ИИ

Три фоновых агента работают автоматически по расписанию (утро/вечер), собирают свежие новости по ИИ и технологиям из бесплатных RSS-источников, анализируют и публикуют отчёты на GitHub Pages как блог.

## 🚀 Как это работает

```
┌─────────────────┐     ┌──────────────────┐     ┌───────────────────┐
│ Агент-поисковик │     │ Агент-аналитик   │     │ Агент-публикатор  │
│ (собирает RSS)  │ ──► │ (фильтрует,      │ ──► │ (генерирует HTML, │
│                 │     │  дедуплицирует,  │     │  публикует на     │
│                 │     │  сортирует)      │     │  GitHub Pages)    │
└─────────────────┘     └──────────────────┘     └───────────────────┘
```

- **GitHub Actions** — бесплатный планировщик (2000 минут/мес)
- **RSS-источники** — бесплатные, без API-ключей
- **GitHub Pages** — бесплатный хостинг для блога с отчётами

## 📦 Возможности

- Собирает новости из 15 бесплатных источников (TechCrunch AI, Hacker News, arXiv, Reddit, VentureBeat, The Verge, MIT News, Google AI Blog и др.)
- Фильтрует мусор (спонсорское, вебинары, реклама)
- Дедуплицирует повторяющиеся новости (по ключевым словам)
- Сортирует по значимости (скоринг: свежесть, крупные игроки, маркеры важности)
- Категоризирует: 🔬 Исследования, 🛠️ Инструменты, 🏢 Компании, ⚖️ Индустрия
- Публикует отчёты на GitHub Pages как блог с архивами
- Защита от повторов — новости публикуются только один раз (история в `data/history.json`)

## 🛠️ Установка (5 минут)

### Шаг 1. Создайте отдельный репозиторий

1. Зайдите на [github.com/new](https://github.com/new)
2. Назовите репозиторий, например `ai-news-agent`
3. Выберите **Public** (бесплатно) или Private (для приватных нужен платный GitHub)
4. Нажмите **Create repository**

### Шаг 2. Загрузите файлы проекта

Всё содержимое этой папки (`ai-news-agent/`) скопируйте в корень нового репозитория.

Проще всего через командную строку:

```bash
# На вашем компьютере в папке ai-news-agent
cd ai-news-agent

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ai-news-agent.git
git push -u origin main
```

### Шаг 3. Включите GitHub Pages

1. В репозитории откройте **Settings → Pages**
2. **Source:** `Deploy from a branch`
3. **Branch:** `main` / папка `/ (root)`
4. Нажмите **Save**

### Шаг 4. Готово! 🎉

Агенты запустятся автоматически по расписанию:
- 🌅 Утренний отчёт: 08:00 UTC
- 🌆 Вечерний отчёт: 18:00 UTC

Ваш блог будет по адресу: `https://ВАШ_ЛОГИН.github.io/ai-news-agent/`

## ⏰ Настройка расписания

Отредактируйте `.github/workflows/agent.yml`:

```yaml
on:
  schedule:
    - cron: "0 8 * * *"   # утро (UTC)
    - cron: "0 18 * * *"  # вечер (UTC)
```

Формат cron: `минута час день-месяца месяц день-недели`

## 🧪 Запуск вручную

В GitHub: **Actions → AI News Agent → Run workflow** — кнопка в любое время.

## 🔧 Добавление своих источников

Отредактируйте список `SOURCES` в `scripts/fetch_sources.py`:

```python
SOURCES = [
    {
        "name": "TechCrunch AI",
        "url": "https://techcrunch.com/category/artificial-intelligence/feed/",
        "keywords": None,  # None = забирать всё
    },
    # добавьте свой RSS-фид сюда
]
```

## ❓ Вопросы

**Почему нужен отдельный репозиторий?**
GitHub Pages публикует сайт из корня репозитория. Чтобы блог работал, весь проект должен быть корнем отдельного репозитория.

**Что если какой-то RSS-источник не отвечает?**
Агенты обрабатывают ошибки отдельных источников без остановки — остальные источники работают. Если источник стабильно недоступен, замените его в списке.

**Как часто обновляется блог?**
По умолчанию 2 раза в день. Что-то срочное — запустите workflow вручную.
